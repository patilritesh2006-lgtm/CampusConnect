# Roles & Permissions

## Super Admin
- Manage colleges
- View all analytics
- Manage platform settings
- Approve colleges

---

## College Admin
- Manage students
- Manage faculty
- Manage clubs
- Create/Edit/Delete events
- Send notifications
- View reports

---

## Faculty
- Create department events
- Verify attendance
- Upload certificates

---

## Club Coordinator
- Manage club events
- View registrations
- Manage club members

---

## Student
- Register for events
- Bookmark events
- Receive notifications
- Download certificates
- Give feedback
