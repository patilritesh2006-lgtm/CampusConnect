# 1. Introduction

CampusConnect is a web application designed to centralize all college events into one platform.

It allows students to discover, register and receive notifications about events while enabling administrators to manage events efficiently.

---

# 2. Purpose

To provide one centralized platform for event management and student engagement.

---

# 3. Scope

The system will provide:

• Student Login

• Admin Login

• Event Management

• Event Registration

• Notifications

• Attendance

• Dashboard
